Flight Booking System

Project Overview

Flight Booking System is a web-based application developed using Django. It allows users to view available flights, book tickets, and manage booking details through a simple and user-friendly interface.

Features

• View available flights
• Search flights
• Book flight tickets
• Enter passenger details
• Manage bookings
• Django Admin Panel
• Responsive user interface

Technologies Used

• Python
• Django
• SQLite
• HTML5
• CSS3
• JavaScript

Installation

1. Clone the repository

git clone https://github.com/Sanjana-S0604/django-flight-booking-system.git

2. Open the project folder

cd django-flight-booking-system

3. Install dependencies

pip install -r requirements.txt

4. Apply migrations

python manage.py migrate

5. Run the server

python manage.py runserver
